# Public release boundaries

This repository contains the Ready Player One application source only.

It intentionally excludes ROMs, cover libraries, BIOS and firmware files, encryption keys, proprietary emulator libraries, purchased software, application installers, credentials, machine addresses, transfer history, generated caches, and compiled RP1/RP2 build output. Redistributable, pinned third-party runtime components required to build RP2 are kept with their licenses.

Users must provide their own legally obtained game and system files. Nothing in this repository grants rights to third-party software or media.
